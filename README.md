## Features

- Product browsing and search
- Product filtering and categories
- Shopping cart and wishlist
- User authentication
- Order placement and tracking
- Customer order management
- Admin dashboard
- Product and order management
- Sales and revenue statistics
- Customer messages and notifications
- Cloud-based image management
- Responsive user interface

## Tech Stack

**Frontend:** React.js, JavaScript, Bootstrap, Material UI, Axios, React Icons

**Admin:** React.js, JavaScript, Bootstrap, Material UI, Axios

**Backend:** Node.js, Express.js, MongoDB, Mongoose

**Cloud & Deployment:** Vercel, Render, MongoDB Atlas, Cloudinary
